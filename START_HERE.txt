MathScope Lab

ใช้งานออนไลน์: อัปโหลด index.html, styles.css, app.js ขึ้น GitHub แล้วเปิด GitHub Pages
(รายละเอียดใน README.md)

ใช้งานในเครื่อง:
1. เปิดโฟลเดอร์นี้ใน Visual Studio Code
2. เปิด Terminal แล้วพิมพ์  npm run dev
3. เปิด http://localhost:5173
(ไม่ต้อง npm install)

ลองเร็วที่สุด: กด "ใช้ภาพตัวอย่าง" → "วิเคราะห์รูพรุน"
อยากรู้ว่าวัดแม่นแค่ไหน: กด "ภาพทดสอบความแม่นยำ"
