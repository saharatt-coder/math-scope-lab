MathVision Lab — Complete Version

วิธีเปิดใช้งาน
1. เปิดโฟลเดอร์นี้ใน Visual Studio Code
2. เปิด Terminal
3. พิมพ์ npm run dev
4. เปิด http://localhost:5173

ไม่ต้องพิมพ์ npm install เพราะเวอร์ชันนี้ไม่ใช้แพ็กเกจภายนอก

ลำดับทดลองเร็วที่สุด
1. กด “ใช้ภาพทดลอง”
2. กด “หา Threshold อัตโนมัติ (Otsu)”
3. กด “วิเคราะห์รูพรุน”
4. เข้า Geometry Lab หรือ Calculus Lab
5. กรอกข้อมูลตัวอย่างแล้วบันทึกเข้าคลัง
6. บันทึกหลายช่วงเวลาเพื่อดู Dashboard การเติบโต
