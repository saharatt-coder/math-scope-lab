# MathScope Lab — Sourdough Pore Analyzer

เว็บแอปสำหรับวัดรูพรุนของขนมปังซาวโดว์จากภาพถ่าย แล้วใช้ผลที่วัดได้เป็นสื่อเรียนเรขาคณิต แคลคูลัส (ผลบวกรีมันน์ → ปริพันธ์) และอัตราการเปลี่ยนแปลง

- ประมวลผลภาพในเบราว์เซอร์ทั้งหมด ไม่มีการส่งภาพขึ้นเซิร์ฟเวอร์
- ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (มีแค่ `index.html`, `styles.css`, `app.js`)
- ใช้ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ

**เปิดใช้งานออนไลน์:** https://saharatt-coder.github.io/math-scope-lab/

---

## วิธีใช้ (4 ขั้น)

1. **เลือกภาพ** หน้าตัดขนมปังที่มีไม้บรรทัดวางข้าง ๆ (ลากไฟล์มาวางได้) หรือกด “ใช้ภาพตัวอย่าง”
2. **ตั้งสเกล** คลิก 2 จุดบนไม้บรรทัด แล้วพิมพ์ระยะจริง เช่น 10 mm
3. **เลือกบริเวณ (ROI)** ลากวงรีหรือสี่เหลี่ยมครอบเฉพาะเนื้อขนมปัง
4. **วิเคราะห์** ระบบเลือก Threshold ให้อัตโนมัติ (Otsu) ปรับเองได้ด้วยแถบเลื่อน และผลจะอัปเดตทันที

จากนั้นไปต่อที่

| แท็บ | ใช้ทำอะไร |
|---|---|
| 2. ประมาณด้วยรูปเรขาคณิต | วางวงกลม วงรี สี่เหลี่ยม หลายเหลี่ยม ให้ทับรูพรุน ดู Percent Error และ IoU |
| 3. แคลคูลัส | แบ่งรูพรุนเป็น n แถบ เปรียบเทียบผลบวกซ้าย/ขวา/จุดกึ่งกลาง/ล่าง/บน คางหมู ซิมป์สัน ดูการลู่เข้าเมื่อ n → ∞ และตารางคำนวณทีละแถบ |
| 4. คลังข้อมูล | บันทึกตัวอย่างพร้อมเวลาหมัก อุณหภูมิ Hydration ความสูงขนมปัง ส่งออก/นำเข้าไฟล์สำรอง |
| 5. Dashboard | กราฟค่าต่าง ๆ ตามเวลาหมัก แยกสีตาม Series และอนุพันธ์โดยประมาณ (ผลต่างสืบเนื่อง) |

1. อัปโหลด `index.html`, `styles.css`, `app.js` (และไฟล์อื่นในโฟลเดอร์นี้) ไว้ที่ root ของ repository

3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

```bash
npm run dev
```

แล้วเปิด http://localhost:5173 (ต้องมี Node.js; ไม่ต้อง `npm install`)

## วิธีคำนวณ

| ค่า | วิธี |
|---|---|
| ภาพระดับเทา | 0.299R + 0.587G + 0.114B |
| Threshold อัตโนมัติ | Otsu (คำนวณจากพิกเซลใน ROI เท่านั้น) — รูคือพิกเซลที่ ≤ t (หรือ > t ถ้าเลือก “รูสว่างกว่า”) |
| ลดจุดรบกวน | Opening แล้ว Closing ด้วยหน้าต่าง 3×3 (พิกเซลนอก ROI ไม่มีผลต่อการกัดกร่อน) |
| แยกรู | Connected components แบบ 8 ทิศ |
| พื้นที่ | จำนวนพิกเซล × (mm ต่อ px)² |
| เส้นรอบรูป | Marching squares แบบถ่วงน้ำหนัก (แนวแกน 0.9473, แนวทแยง 0.6735) |
| เส้นผ่านศูนย์กลางสมมูล | 2√(A/π) |
| Circularity | 4πA / P² (วงกลม = 1) |
| Porosity | พื้นที่รูที่นับ ÷ พื้นที่ ROI |
| สัดส่วนพิกเซลรูทั้งหมด | พิกเซลรูทุกพิกเซล (รวมรูที่ถูกตัดออก) ÷ พื้นที่ ROI |
| S.D. | ส่วนเบี่ยงเบนมาตรฐานของกลุ่มตัวอย่าง (หาร n − 1) |

ภาพที่ ROI ยาวเกิน 2000 px จะถูกย่อให้ด้านยาวเหลือ 2000 px ก่อนประมวลผล แล้วแปลงผลกลับเป็นพิกเซลของภาพจริง

**ฟังก์ชันในแท็บแคลคูลัส:** f(x) คือความยาวรวมของรูพรุนในแนวตั้งที่ตำแหน่ง x (หลักของคาวาเลียรี) ค่าของแต่ละคอลัมน์พิกเซลวางไว้ที่จุดกึ่งกลางคอลัมน์ แล้วเชื่อมด้วยเส้นตรง ทำให้ ∫₀ᴸ f(x) dx เท่ากับพื้นที่ที่นับจากพิกเซล **พอดี** ดังนั้นทุกวิธีจึงลู่เข้าสู่พื้นที่จริงเมื่อ n → ∞ และผลบวกล่าง ≤ พื้นที่จริง ≤ ผลบวกบน เสมอ

## ความแม่นยำ (ทดสอบแล้ว)

ทดสอบด้วยภาพสังเคราะห์ที่รู้ขนาดจริง (วงกลม วงรี สี่เหลี่ยม สามเหลี่ยม ทั้งแบบมีและไม่มีสัญญาณรบกวน และภาพกว้าง 1200–5000 px) กดปุ่ม **“ภาพทดสอบความแม่นยำ”** ในแอปเพื่อดูผลเทียบแบบเดียวกันได้เอง

| รัศมีของรูบนภาพ | พื้นที่คลาด | เส้นรอบรูปคลาด | Circularity ของวงกลม |
|---|---|---|---|
| 4–6 px | ≤ 3.5% | ≤ 1.2% | 0.98–1.00 |
| ≥ 9 px | ≤ 1% | ≤ 1% | 0.98–1.00 |

ข้อจำกัดที่ควรรู้

- ความแม่นยำข้างบนคือความแม่นยำของ **อัลกอริทึม** ภาพจริงยังขึ้นกับแสง มุมกล้อง ความคมของหน้าตัด และการเลือก Threshold
- ค่าที่ได้เป็นพื้นที่บนหน้าตัด 2 มิติ ไม่ใช่ปริมาตรของรู
- รูที่ติดกันในภาพจะถูกนับเป็นรูเดียว
- รูปทรงมุมฉากที่วางตรงแนวแกนพอดี (ไม่ค่อยพบในขนมปัง) มีเส้นรอบรูปต่ำกว่าจริง ~5%
- ถ้าเปิด “ลดจุดรบกวน” รูที่เล็กกว่าประมาณ 3×3 พิกเซลจะหายไป

### เวอร์ชันก่อนหน้านี้ต่างกันอย่างไร

เวอร์ชันแรกนับเส้นรอบรูปจากขอบของพิกเซล ทำให้เส้นรอบรูปเกินจริงประมาณ 27% และวงกลมสมบูรณ์ได้ Circularity เพียง ~0.62 นอกจากนี้ยังย่อภาพเหลือ 900 px ก่อนประมวลผล ทำให้รูเล็กคลาด ~8% เวอร์ชันนี้แก้ทั้งสองข้อแล้ว **ค่า Circularity และเส้นรอบรูปที่บันทึกจากเวอร์ชันเก่าจึงเทียบกับเวอร์ชันนี้ไม่ได้** (ส่วนพื้นที่เทียบได้)
